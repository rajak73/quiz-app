📖 User Manual / Guide

🚀 1. Getting Started

  • Upload: Use .xlsx or .csv files.
  • Subject: Organize files (e.g., Physics, GK) using "+ Add New".
  • Control Center: Drag the floating "G" button for menu.

⚡ 2. Quiz & Practice Modes

  • Normal Mode: Exam style with Timer. Result at end.
  • Practice Mode: Instant feedback.
    • Correct = Auto-Next (Removes from Error List).
    • Wrong = Adds to Error List.
  • Smart Filters: Mix "Unattempted" + "Wrong History" to master a topic.

📖 3. Quick Revision (Read)

  • Zoom: Use A+ / A- buttons in sticky header.
  • Sheet Tags: Enable "View Sheet Name" from Menu (☰).
  • Focus View: Double click any text to copy/share.

⌨️ 4. Shortcuts & Gestures

  • Full Screen: Double-tap the Timer.
  • Swipe: Left/Right navigation on Mobile.
  • Keys: Enter (Next), F (Full Screen).
  • Tools: T (Translate), M (Mark Review).
  • Options: Press 1, 2, 3, 4 to select answer.

🛠️ 5. Smart Tools

  • Translate (文): Hindi Translation.
  • Copy (📋): Smart Copy (Question + Options).
  • Share (➤): Create beautiful Image Cards.
  • AI Search (🔍): Google Explanation.

⚠️ 6. Settings & Data Warning

  • Backup: Always use "Export Data" before clearing browser cache.
  • Deleting a Subject or File permanently deletes its Test History and Notes.
